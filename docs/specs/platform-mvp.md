# 平台 MVP：消息 / 社交登录 / 实时推送 / 租户套餐 / 治理与可观测

## Problem Statement

CRM 与 OA 已交付，但后续业务套件（mall/erp/pay/mp/member/ai）依赖的平台能力仍然缺失：没有短信/邮件通道，没有第三方社交登录，站内通知只能 60 秒轮询，租户超管是通配权限、无法按套餐售卖，也没有访问日志、敏感词、地区库、数据库文档和运行监控。这些能力不补齐，每上一个新套件都要重复造轮子，且 SaaS 化无从谈起。

## Solution

一次交付九块平台能力，按依赖分批：

1. **租户套餐与配额**：套餐定义菜单与用户数/存储/短信/邮件配额；租户超管权限从通配改为套餐内菜单，平台租户保持通配；存量租户迁移回填全部菜单。
2. **消息通道**：新 `message` 模块，平台级渠道/模板 + 租户级发送日志；provider 注册表内置 `log`、`smtp`、`aliyun_sms`；密钥查询脱敏，手动重发。
3. **社交登录**：微信开放平台 / 钉钉 / 企微 OAuth2 客户端；state + PKCE；未绑定不自动建号。
4. **实时推送**：`pkg/push` 统一 hub 与一次性票据；SSE 与 WebSocket 双传输；前端 WS → SSE → 轮询降级。
5. **访问日志**：`infra_api_log` + Auth 后中间件 + 异步批量落库 + 脱敏 + 保留期清理。
6. **敏感词**：租户级词库 + rune trie，接入公告与 CRM 跟进。
7. **地区与 IP**：`system_area` 省市种子 + 导入；可选 ip2region xdb，登录日志查询时补归属地。
8. **数据库文档**：抽取 `pkg/dbschema`，复用给 codegen 与新的 DB 文档页/Markdown 导出。
9. **监控面板**：runtime、DB 连接池、调度器、租户/用户、访问与消息聚合；不引入 Prometheus/pprof。

详细规则、表结构、API、迁移号与验收见 `docs/platform-mvp-spec.md`。

## User Stories

1. 作为平台管理员，我可以创建套餐并勾选可访问菜单，设置用户数/存储/短信/邮件配额。
2. 作为平台管理员，我新建租户时选择套餐，租户管理员登录后只看到套餐内菜单。
3. 作为平台管理员，我修改套餐后，该租户的菜单权限立即生效。
4. 作为平台管理员，我删除被租户引用的套餐时收到 409 提示。
5. 作为租户管理员，我能看到本租户的配额上限与已用量。
6. 作为平台管理员，我配置短信/邮件渠道与模板，并用测试发送验证连通性。
7. 作为租户用户，我触发的短信/邮件发送会写入本租户日志，失败可手动重发。
8. 作为平台管理员，我查询渠道配置时看不到明文密钥。
9. 作为租户用户，我本月短信/邮件用量达到套餐上限时收到明确报错。
10. 作为租户用户，我用微信/钉钉/企微扫码登录已绑定的账号。
11. 作为租户用户，未绑定社交账号时收到「先登录后绑定」的提示，而不是被自动建号。
12. 作为租户用户，我在个人中心绑定/解绑社交账号。
13. 作为平台管理员，我管理社交登录客户端配置。
14. 作为登录用户，我收到站内通知时铃铛在 1 秒内更新，无需等 60 秒轮询。
15. 作为登录用户，WebSocket 不可用时自动降级到 SSE，再降级到轮询。
16. 作为平台管理员，我按用户/方法/路径/状态/时间查询 API 访问日志并清空。
17. 作为平台管理员，我设置访问日志保留天数，系统每天自动清理。
18. 作为租户管理员，我维护本租户敏感词，并在公告/跟进内容命中时收到 400 与命中词。
19. 作为登录用户，我在表单里使用省/市/区三级地区选择器。
20. 作为平台管理员，我导入区县地区数据。
21. 作为平台管理员，我在登录日志里看到 IP 归属地。
22. 作为平台管理员，我浏览数据库表结构并导出 Markdown 文档。
23. 作为平台管理员，我在监控面板看到进程、DB 连接池、调度器、租户/用户、访问与消息指标。
24. 作为开发者，我在空库启动时自动获得新菜单、默认渠道/模板、标准套餐与省市数据。
25. 作为开发者，我升级存量库时新菜单自动补齐、租户超管权限不丢失。

## 实现与测试

- 每单独立工作树 `../go-admin-pro-<n>-<slug>` + `feat/<n>-<slug>`，集成分支 `feat/platform-mvp`，同时最多 2 个实现器。
- 每单合并后跑五验证：`make check`、`make test-integration`、`make verify-migration`（66 表）、`make web-type-check`、`make web-build`。
- 集成测试覆盖：套餐外 403、平台租户通配、配额边界、模板参数 400、provider 失败落日志、密钥脱敏、社交 state 重放/未绑定 409、推送票据一次性、访问日志脱敏与 Flush、敏感词命中、地区种子幂等、DB 文档范围、监控平台权限。
- 真实三方凭据不在仓库验证：SMTP/阿里云/微信/钉钉/企微全部用 mock 端点；另提供 `log` provider 与配置样例。

## Out of Scope

- 自家 OAuth2 授权服务器、社交自动建号、短信验证码登录。
- 短信/邮件自动重试、批量发送、附件。
- 多实例推送（Redis/NATS）、Prometheus/pprof/链路追踪。
- 密钥 KMS 加密、地区区县内置数据、套餐计费/试用/续费。

## Further Notes

- ADR 0009 的「通知仅站内」边界被 ADR 0010/0013 部分取代；OA 自身仍按站内信实现。
- 消息/社交密钥 DB 明文，仅 API 脱敏；后续接 KMS。
- 推送与票据为进程内实现，单实例限制写入 ADR。
- 存量库若 `database.seed=false`，新菜单仍需手工创建。
