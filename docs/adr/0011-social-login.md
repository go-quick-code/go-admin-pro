# 社交登录：只做第三方 OAuth2 客户端

**Status**: accepted

社交登录只实现「用微信开放平台/钉钉/企微账号登录已绑定的本地用户」，不做自家 OAuth2 授权服务器（不向第三方 App 签发 token）。流程用服务端一次性 state + PKCE，回调校验 provider/redirect 完全匹配；未绑定账号返回 409 并提示先登录再绑定，**不自动建号**。原因：当前没有第三方 App 消费方，授权服务器工作量约翻倍；后台管理系统自动建号会绕过租户的开户与配额流程，安全与运营风险都高。代价：新用户必须先由管理员创建本地账号再绑定；后续要做开放平台时另立 ADR。

相关：ADR 0012（租户套餐）、`docs/platform-mvp-spec.md` §4.4。
