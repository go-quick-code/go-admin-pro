# API 访问日志：Auth 之后采集，异步批量落库，默认保留 30 天

**Status**: accepted

新增 `infra_api_log`，在 `Auth` 之后、`OperateLog` 之前挂中间件，记录全部受保护请求（含 GET）；写入走进程内有界队列 + 批量插入（200 条或 1 秒），队列满丢弃并计数告警，绝不影响请求。query 参数按名称脱敏并截断，不记录请求体；保留期默认 30 天，系统级 cron 每日清理。原因：现有 `AccessLog` 只写 slog、且在 `Auth` 之前拿不到用户/租户；操作日志只记写请求，无法回答「谁在什么时候访问了什么」。异步批量把日志写入从请求路径移开，避免高频 GET 拖慢接口。代价：进程崩溃时队列中未落库的日志会丢失；多实例各自缓冲，排序不保证；不做采样与全文检索。

相关：`docs/platform-mvp-spec.md` §4.6。
