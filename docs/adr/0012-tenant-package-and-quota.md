# 租户套餐：菜单授权 + 配额，平台租户保持通配

**Status**: accepted

租户套餐同时约束菜单与配额（用户数/存储/短信/邮件）。平台租户（ID=1）的 `super_admin` 保持通配权限、全部菜单与「全部」数据范围；其他租户的 `super_admin` 不再通配，权限与菜单来自 `system_role_menu`，数据范围按角色 `data_scope`。绑定套餐时在事务内重写该租户超管角色的菜单，并清空权限缓存；迁移 00023 为存量租户回填全部菜单，避免升级失权。原因：只要租户超管仍是通配，套餐就只是配额而不是「卖功能」；把通配限定在平台租户，才能让套餐真正决定可见能力，同时保留平台运维的兜底通道。代价：这是一次权限语义的破坏性变更，需要回填迁移、三处语义测试与文档说明；租户超管不能再绕过套餐。

相关：ADR 0004（数据权限）、`docs/platform-mvp-spec.md` §4.1/§4.2。
