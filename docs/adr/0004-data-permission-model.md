# 数据权限：角色范围上限 + 负责人归属 + 自定义部门并集

**Status**: accepted

角色 `data_scope` 决定可见范围上限（全部 / 自定义部门 / 本部门 / 本部门及以下 / 仅本人），业务记录再用 `owner_user_id` 与 `owner_dept_id` 过滤；多角色取可见部门并集，任一角色为「全部」则全可见。原因：CRM 的「我的客户」本质是负责人归属，不是创建人；纯部门树无法表达销售跨部门跟进。代价：每张 CRM 主表都要维护 owner 与部门快照，负责人变更要写审计历史；自定义部门需要新增 `system_role_dept` 表。
